# Qwen3-VL Eval

Evaluation scripts and results for Qwen3-VL.

## Overview

This repository contains evaluation code, datasets, and analysis for the Qwen3-VL vision-language model.

## Structure

- `eval/` — Evaluation scripts
- `data/` — Datasets and annotations
- `results/` — Output results and metrics
- `notebooks/` — Analysis notebooks

## Usage

```bash
pip install -r requirements.txt
python eval/run_eval.py
```
